# AI Refrigeration Platform

Plataforma de monitoramento e automação para sistemas de refrigeração e climatização, com foco em operação inteligente, análise de dados e apoio à tomada de decisão.

## Visão geral

O projeto foi desenvolvido para centralizar informações de equipamentos, acompanhar estados operacionais e reduzir atividades manuais relacionadas ao monitoramento de climatização.

A solução combina desenvolvimento web, automação e inteligência artificial, incluindo uso de **LLMs locais**, **IA generativa** e execução em ambiente **Linux/Ubuntu**.

## Principais recursos

- Monitoramento de equipamentos de refrigeração e ar-condicionado
- Consolidação de estados e informações operacionais
- Regras inteligentes para análise de temperatura e comportamento dos equipamentos
- Uso de IA generativa para análise e recomendações
- Integração com modelos locais de linguagem
- Estrutura preparada para automações e tomada de decisão baseada em dados
- Operação em ambiente Linux

## Tecnologias e conceitos

- Linux / Ubuntu
- LLMs locais
- IA generativa
- APIs e integrações
- Automação de processos
- Desenvolvimento web
- Monitoramento operacional

## Objetivo técnico

O objetivo principal é transformar um processo operacional reativo em um fluxo mais inteligente e orientado por dados, permitindo identificar inconsistências, acompanhar equipamentos e apoiar decisões com automação e IA.

## Observação

Este repositório representa um projeto desenvolvido em contexto corporativo. Informações sensíveis, credenciais, dados internos, endpoints privados e regras específicas de negócio não são expostos publicamente.
